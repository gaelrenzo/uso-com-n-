# Alternativas de código abierto

Encuentra programas abiertos que resuelvan la tarea concreta que describe el usuario.

## Flujo

1. Identifica la tarea, los requisitos esenciales y el sistema operativo. Si falta el sistema, pregunta cuando cambie sustancialmente las opciones; de lo contrario, declara la suposición.
2. Busca opciones actuales en la web. Prioriza los sitios oficiales, repositorios oficiales y páginas de licencia.
3. Verifica que cada candidato tenga licencia libre/open source identificable. No confundas código abierto con freeware, freemium, prueba gratuita o código visible con licencia restrictiva.
4. Compara qué necesidades cubre, limitaciones, formatos, sistemas compatibles, funcionamiento local o web, cuenta requerida y funciones que podrían ser de pago.
5. Recomienda las opciones más adecuadas a la necesidad. Explica brevemente cuál probar primero y por qué; evita presentar herramientas que solo coincidan superficialmente.

## Verificación

- Enlaza la página oficial, el repositorio oficial y la licencia cuando estén disponibles.
- Indica el nombre exacto de la licencia y verifica compatibilidad y mantenimiento con información reciente.
- Distingue hechos confirmados de datos no verificados; marca estos últimos como “por confirmar”.
- No presentes una alternativa parcial como reemplazo equivalente completo.
- Si el usuario solo describe una necesidad, busca desde esa necesidad; no exijas que nombre primero el producto comercial.
- Si menciona “ArtCraft/Artcraft” y no se puede identificar con certeza, solicita el enlace o nombre exacto.

## Respuesta

Responde en español salvo que el usuario prefiera otro idioma. Empieza con una recomendación breve y usa una tabla compacta:

| Programa | Adecuación | Licencia | Sistemas | Límites relevantes | Enlaces oficiales |
|---|---|---|---|---|---|

Termina con la opción recomendada y el siguiente paso para probarla o migrar.

## Ejemplos

- “Necesito dibujar y pintar digitalmente.”
- “Busco editar video sin suscripción.”
- “¿Qué programa abierto sirve para modelado 3D?”
- “Quiero una alternativa libre para CAD eléctrico en Windows.”
